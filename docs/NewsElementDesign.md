# News Element – Fundamental News Overview

## Overview
The **News Element** tab consolidates macro‑economic releases that fundamental traders rely on. Each release is displayed as a compact card showing the three core **supporting elements**:
- **Previous** – the value from the prior period
- **Actual** – the newly released figure
- **Forecast** – the consensus estimate from analysts

Each card also includes a **source link** for verification and a tiny **sparkline** visualising the three points.

## How Traders Use This Tab
- **Identify surprises:** Compare *Actual* vs *Forecast*; a large deviation may trigger a **Buy** or **Sell** decision.
- **Cross‑check sources:** Click the source link to view the full release and commentary.
- **Quick glance:** The sparkline summarises the three data points at a glance.

*The tab is read‑only; no automated trade signals are provided to keep decision‑making fully under the trader’s discretion.*

## Implementation Guidance

### Rendering the Cards

Create a reusable React component `EconomicCard` that receives the following props:
- `title` – Indicator name (e.g., "Core CPI")
- `data` – Object containing `previous`, `actual`, `forecast`, and `source` URLs.
- `sparklineUrl` – URL to the sparkline image generated via QuickChart.

```tsx
// components/EconomicCard.tsx
import Image from 'next/image';

interface Props {
  title: string;
  data: {
    previous: string;
    actual: string;
    forecast: string;
    source: string;
  };
  sparklineUrl: string;
}

export default function EconomicCard({ title, data, sparklineUrl }: Props) {
  return (
    <div className="bg-gray-800 rounded-lg p-4 shadow-md hover:shadow-lg transition-shadow">
      <h3 className="text-xl font-semibold text-white mb-2">{title}</h3>
      <table className="w-full text-sm text-gray-200 mb-2">
        <tbody>
          <tr><td>Previous</td><td className="text-right">{data.previous}</td></tr>
          <tr><td>Actual</td><td className="text-right font-medium text-green-400">{data.actual}</td></tr>
          <tr><td>Forecast</td><td className="text-right">{data.forecast}</td></tr>
          <tr><td>Source</td><td className="text-right"><a href={data.source} target="_blank" rel="noopener" className="underline">Link</a></td></tr>
        </tbody>
      </table>
      <Image src={sparklineUrl} alt={`${title} sparkline`} width={300} height={80} className="rounded" />
    </div>
  );
}
```

### Adding to the News Element Tab

In `components/slides/news-element-slide.tsx`, import the component and map the indicators defined in the markdown to a JSON configuration (e.g., `data/economicIndicators.json`). Render them in a responsive grid:

```tsx
import EconomicCard from '@/components/EconomicCard';
import indicators from '@/data/economicIndicators.json';

export default function NewsElementSlide() {
  return (
    <section className="p-6 grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6">
      {indicators.map((i) => (
        <EconomicCard
          key={i.id}
          title={i.title}
          data={i.data}
          sparklineUrl={i.sparklineUrl}
        />
      ))}
    </section>
  );
}
```

### Data Source

Create a simple script (Node/TS) that fetches the latest releases from the public APIs (BPS, Federal Reserve, etc.) and writes `economicIndicators.json`. Schedule it as a daily cron job using Vercel's serverless functions or a CI pipeline.
